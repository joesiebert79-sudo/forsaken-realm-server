# Approved world and environment references

These five PNGs are the original, unmodified images supplied in `forsaken-realm-approved-5-reference-images.zip` for [Issue #2](https://github.com/joesiebert79-sudo/forsaken-realm-server/issues/2). They are the authoritative visual references for the world replacement. Keep approved building models, floor plans, textures, and gameplay systems separate from this reference set.

| Repository file | ZIP entry | Purpose |
| --- | --- | --- |
| `The Forsaken Realm - Blood & Iron Map.png` | `The Forsaken Realm: Blood & Iron Map.png` | Geography and relative positions of 12 villages, two trader towns, and five castles |
| `Forsaken Realm Village and Castle Guide.png` | same | Village composition, names, environments, castle settings |
| `Medieval Village RPG Plaza.png` | same | Village plaza and approved building arrangement |
| `Torchlit Medieval Fantasy Village.png` | same | Rural village environment and lighting |
| `Isometric Fantasy Harbour Trading Town.png` | same | Coastal trader town arrangement and streets |

Windows cannot store a colon in a filename, so the first ZIP entry has a hyphen in this repository. Its PNG bytes are unchanged. SHA-256 checksums are in `SHA256SUMS`.
