# Forsaken Realm v0.80 menus

The main menu, settings, character selection/creation, market and shared inventory/service panels now use dark iron panels, aged gold trim and serif text based on the approved menu references. The existing clean castle background and Forsaken Realm name remain. All buttons and product cards use actual game data.

The recovered reference folder calls these Day 8 approved menus; the Day 4 gameplay work remains described in DAY4-STATUS.md. Original pictures are preserved under references/day8-approved. Mockup titles, placeholder characters, unsupported roles and cash prices are not game data. Only Farmer and Hunter are available to new characters; legacy roles remain intact. Cash purchasing remains unavailable.

Equipment, companions, resources, farming, furniture, cosmetics, bundles and coin exchange have relevant stock. Houses show five real banker deed options and require the normal banker visit/account/bank balance. Four portable furnishing kits can be bought, carried and placed outdoors beside an owned active settlement flag. Wardrobe shows owned cosmetics and Marketplace shows actual player listings.

10 copper = 1 silver; 10 silver = 1 gold. Mixed coins are accepted, including 1 silver + 48 copper for a 2-silver purchase. Coin exchange has no fee and preserves value.

Validation: supported server regression suite, market category/transaction/capacity/kit placement checks, client coin arithmetic and individual-stack tap checks, signed Android build. Desktop render previews exercise the actual menu drawing code with graphics adapters; they are not physical Android screenshots. Phone layout and gameplay testing remain with the player.
